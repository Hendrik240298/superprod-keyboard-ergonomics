# Keyboard Ergonomics: idea

Make [Super Productivity](https://github.com/super-productivity/super-productivity) more comfortable to navigate with a keyboard. The [Project Kanban plugin](https://github.com/Hendrik240298/superprod-kanban) demonstrated a useful custom-plugin workflow; this plugin addresses global navigation rather than project-local boards.

Starting goal: a searchable keyboard picker for Inbox, Today, projects, and other app views. Keep the app's existing bindings for Inbox and Today; let users choose a free combination for the picker. Only add further shortcuts or Vim-like motions after real use establishes a need, and do not take over typing in inputs.

See [PLAN.md](PLAN.md) for what is implemented and what still needs verification.
